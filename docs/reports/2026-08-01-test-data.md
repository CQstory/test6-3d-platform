## 八、需要动态创建数据的场景

| 场景 | 前置步骤 |
|------|----------|
| 店铺审核 `GET /admin/shops/pending` | 用普通用户调 `POST /shops` 申请入驻（status 变为 pending） |
| 店铺驳回/通过 `POST /admin/shops/{id}/approve\|reject` | 同上 |
| 模型审核 `GET /admin/models/pending` | 用商户调 `POST /models` 上传模型（status 变为 pending_review） |
| 模型驳回重提 `PUT /models/{id}` | 先驳回一个模型再修改 |
| 套餐上限拦截（基础版 slots=3） | 用基础版店铺上传第 4 个模型应返回 400 |
